## 从零搭建海战 Demo《钢铁怒潮 IRON TIDE》
- 交付单页 Canvas 2D 游戏，零依赖、可离线，`file://` 直接打开 index.html 即可运行（普通 script 标签，无 module/fetch）。
- 文件结构：`index.html`、`css/style.css`、`js/engine.js`（数学工具 / Web Audio 程序化音效 / 粒子系统 / 海面纹理 / 舰船矢量绘制）、`js/game.js`（Ship/Shell/Torpedo 实体、敌方 AI、HUD、主循环）。
- 玩法：车钟 -1~Ⅳ 档 + 舵角惯性、炮塔转速限制、齐射散布与炮弹飞行时间、二次迭代提前量解算、核心区暴击、起火/进水持续伤害、三枚扇面鱼雷、DD/CA/BB 三艘敌舰绕圈 AI、雷达小地图、屏幕边缘目标指示、结算战绩。
- 操作：W/S 升降档、A/D 转舵、Q 回中、E 急停、鼠标/左键/空格瞄准开火、F 鱼雷、X 火控辅助、滚轮缩放、M 静音、P 暂停；移动端虚拟摇杆 + 开火/鱼雷按钮，触屏默认开启火控辅助。
- 关键调参决策：交战距离 700~1150、玩家射程 1500、炮弹速度 620、镜头 zoom 视口自适应 0.5~0.9。最初用 6400 世界 / 2050 射程导致敌舰几乎全在屏幕外、鼠标够不着瞄准点，压缩尺度并拉远镜头后解决；WORLD 扩到 16000 避免长时间机动撞边界。
- 视觉：预渲染海面波纹纹理平铺 + 洋流层 + 云影 + 礁石浅滩 + 尾迹泡沫 + 粒子爆炸/水柱 + 屏幕震动；深色海军风 HUD，CSS `clip-path` 切角面板。
- 验证：Chrome headless + CDP 自动化脚本，桌面 12 秒击沉 1 艘敌舰、玩家血量正常下降；390x844 触屏布局无重叠/裁切；控制台 0 错误。

## 修复：A / D 转向失效（用户反馈）
- 根因：`keydown` 里漏了 A/D 分支，`rudderTarget` 只在 `keyup` 中赋值，导致按住时舵角始终为 0、松开时立刻归零。
- 修复：抽出 `syncRudder()`，在 keydown（`e.repeat` 判断之后）、keyup、startGame 三处同步；这样 `Q` 回中不会被按键重复事件覆盖，同时按 A+D 会互相抵消。
- 附带改进：舵效速度系数下限 0.12 → 0.35（停车时也能感知转向）；HUD 舵条增加罗盘航向读数（触屏用短格式避免溢出）；开始界面与帮助文本标注「按住」。
- 验证：按住 D 航向 000°→038°→115°，按住 A 回落到 070°，松舵回正、Q 回中均正常；整体回归桌面/移动端 0 错误，12 秒击沉 1 艘且交战距离保持在 782。

## 改为慢节奏战斗（用户反馈「速度太快，反应不过来」）
- 新增 `PACES` 节奏表（`game.js` 参数区），默认 `slow`，可随时按 `T` 或点 HUD 右侧「慢/标」按钮切换 `normal`（原速）。`P()` 统一读取当前档位。
- 核心机制：`frame()` 里 `dt = realDt * P().time`（慢速 0.6），世界/弹丸/AI/伤害/画面动画统一放慢；`G.realTime` 与 `G.visTime` 分别记录真实时长与视觉时间，HUD 与结算的秒数、航速读数都按 `1/time` 换算成真实感知值。
- 手感补偿：**舵角、炮塔、车钟加速用 `rdt = dt / P().time`（真实时间）**，慢节奏下操作依旧跟手，只有船体位移/转向角速度变慢；本舰装填 `playerReload 0.72` 抵消时间缩放，输出节奏基本不变。
- 敌方弱化：装填 ×1.2、伤害 ×0.75、散布 ×1.45、预判误差 ×1.3、开局首炮缓冲 `rand(5,9)*1.2` 游戏秒；鱼雷航速 ×0.8、间隔 ×1.25；敌方落点预警从飞行 20% 进度开始显示。本舰耐久 ×1.45（15 000→21 750）、火力 ×1.1。
- 装填进度条改用 `reloadMax / torpReloadMax` 分母（因倍率会改变实际装填时长）；切档时按 `playerHp` 倍率等比换算当前 HP，血条不跳变。
- UI：`index.html` 加 `btnPace`（hud-side 第 4 个按钮）与 `paceTag` 顶部徽标，`style.css` 加 `.pace-on` / `.pace-tag`；开始界面、帮助面板补充 T 键说明。
- 验证（CDP headless）：静止挂机 25 秒对比——慢节奏 HP 98%、标准节奏 HP 26%（标准 10 秒即掉 12%、15 秒掉 58%）；慢节奏+火控辅助 25 秒全灭 3 艘、结算时长 00:25、伤害 73 280、命中 79%；切档 HP 等比换算正确、装填显示按真实秒递减；A/D 转向 000°→069°→Q 回中正常；桌面与 390×844 触屏布局无重叠、控制台 0 错误。

## 新增：选择战舰 + 增减队友/敌舰（用户反馈）
- `PLAYER_SHIPS` 三种玩家舰：DD 疾风（15000 HP / 4 管 / 强鱼雷）、CA 赤潮（26000 / 6 管 / 中鱼雷）、BB 铁壁（48000 / 8 管 / **无鱼雷**）；`playerDef(key)` 取配置，HUD 本舰卡与武器标签随选舰同步。
